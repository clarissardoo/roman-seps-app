Website tool for visualizing Roman CGI reflected-light target orbits.

Access at https://roman-seps-app-production.up.railway.app/ 

Radial velocity posteriors computed by S. Blunt.  
Plots and visualizations by C. Do Ó, E. Bogat, K. Stapelfeldt, V. Bailey, and M. Ygouf.
